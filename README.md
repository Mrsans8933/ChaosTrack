# 🎵 ChaosTrack

**ChaosTrack** — Это аудиоплеер, который случайным образом выбирает и воспроизводит музыку из указанной папки.  
Идеален для тех, кто устал от выбора треков и хочет довериться случайности.
---

## ✨ Возможности

- 🎲 Случайное воспроизведение треков
- ⏱️ Отображение текущего времени и общей длительности
- 🚀 Работает без Python (после сборки в `.exe`)
- 🕹️ Возможность выбора папки с музыкой, и менять управления под свои кнопки.
- 🖥️ Рабочий интерфейс
- ⚙️ Удобное меню конфига
- 🖼️ Отображение обложек треков (если есть в MP3)
---
## 🎮 Управление

- ⏸ / ▶ — пауза / продолжение
- 🔊 — слайдер громкости
- ⚙️ — открыть настройки (выбрать папку с музыкой)
## 🚀 Установка и запуск

### 1. Клонируй репозиторий

```bash
git clone https://github.com/Mrsans8933/ChaosTrack
cd ChaosTrack
```
### 2. Установи зависимости
```bash
pip install -r requirements.txt #установка библеотек (зависимостей)
```
### 3. Запусти
```bash
python ChaosTrack.py
```

## Для обычных людей которые хотят все здесь и сейчас (для Windows): https://github.com/Mrsans8933/ChaosTrack/releases/latest
### Просто установите репозиторий и откройте ChaosTrack.exe
